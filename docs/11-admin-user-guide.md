# 11 · 后台使用手册

后台地址：

```text
https://admin.weppp.cyou
```

后台用于写文章、发布内容、审核评论、查看统计和触发主站重建。所有写操作都会走 server，内容真源仍是仓库中的 `content/` 文件和 `data/taoran.db`。

## 1. 登录

打开后台后输入管理员口令登录。生产环境没有默认口令；开发环境未配置哈希时才使用 `taoran-dev`。

如果登录后又回到登录页，优先检查：

- 口令是否正确
- 浏览器是否禁用了 Cookie
- `https://admin.weppp.cyou/api/health` 是否返回 JSON

## 2. 仪表盘

仪表盘展示：

- 今日 PV
- 7 日 PV
- 30 日 PV
- 已发布和草稿数量
- 总捏数
- 待审评论数量
- 30 日浏览趋势

“待审评论”卡片可以直接进入评论审核页。

## 3. 文章列表

入口：左侧导航“文章”。

文章列表展示标题、状态、日期、PV、点赞和评论数量。顶部筛选支持：

- 全部
- 已发布
- 草稿

点击文章标题进入编辑页。点击“删”会把文章目录移入 `content/.trash`，不是直接物理删除；必要时可在服务器上手动找回。

## 4. 新建文章

点击“＋ 新文章”进入编辑页。

必填项：

- 标题
- slug
- 正文

slug 规则：

- 只使用小写字母、数字和连字符
- 示例：`my-first-post`
- 发布后不要随意修改；已发布文章的 slug 会被锁定

右侧字段：

| 字段 | 说明 |
| --- | --- |
| 摘要 | 文章列表、SEO 和卡片摘要使用；可留空 |
| 标签 | 用逗号分隔，最多保留 8 个 |
| 置顶 | 文章列表中优先展示 |
| 开放评论 | 控制这篇文章是否允许评论 |

新文章必须先保存一次草稿，才可以上传图片。原因是图片要落到对应文章目录中。

## 5. 编辑正文

正文编辑器支持两种模式：

- 富文本
- MD 源码

工具栏按钮：

| 按钮 | 功能 |
| --- | --- |
| B | 加粗 |
| I | 斜体 |
| H2 | 二级标题 |
| H3 | 三级标题 |
| • | 无序列表 |
| 1. | 有序列表 |
| “ | 引用 |
| `</>` | 代码块 |
| 链接 | 插入或取消链接 |
| 插图 | 上传图片，保存草稿后可用 |

Markdown 是内容真源。富文本视图只是编辑投影；遇到复杂格式时，可以切到 MD 源码直接修。

## 6. 保存与发布

编辑页右侧有三个主要操作：

- 存草稿：保存内容，但不触发主站重建。
- 发布：把文章状态改为已发布，并触发主站重建。
- 保存并重建：已发布文章修改后使用，保存并触发主站重建。
- 转回草稿：已发布文章下线，并触发主站重建。

发布或修改已发布文章后，server 会把重建任务排队。当前防抖时间约 10 秒，连续保存会合并。

保存文章前，后台会先让 server 做 MDX 语法检查。检查失败时不会写入文章文件，也不会触发主站重建；页面会提示大致行列和错误原因。常见原因包括把 HTML/JSX 片段直接写进正文、没有用代码块包住形如 `</div>` 的内容、链接没有写成 `[文字](地址)`。

草稿保存也会检查 MDX 语法。原因是 Astro 构建会同步 `content/posts` 下所有文章文件，坏草稿同样可能拖垮下一次主站构建。

## 7. 图片上传

新文章先存为草稿后，工具栏会出现插图能力。上传后：

1. server 使用 Sharp 转为 WebP。
2. 图片写入文章目录。
3. 编辑器插入相对 Markdown 引用。
4. 构建时主站再走图片管线。

建议：

- 上传前先压缩超大原图。
- 一篇文章的配图放在文章目录内，不要手动引用外部临时链接。

## 8. 动态

入口：左侧导航“动态”。

动态会写入 `content/moments/YYYY-MM.jsonl`。新增或删除动态后，后台会自动触发主站重建，因为 `/moments/` 是静态页面。

字段：

- 内容：动态正文。
- 心情：可选，适合放一个短标记。
- 位置：可选。
- 时间：默认当前时间，可手动调整。

## 9. 友链

入口：左侧导航“友链”。

友链会写入 `content/friends.json`。新增或删除友链后，后台会自动触发主站重建，因为 `/friends/` 是静态页面。

字段：

- 名称
- 地址
- 头像
- 描述

地址和头像需要是完整 URL。

## 10. 评论审核

入口：左侧导航“评论”。

评论状态：

- 待审
- 已通过
- 垃圾
- 回收站

可执行操作：

- 通过：评论在主站展示。
- 待审：退回审核队列。
- 垃圾：标记为垃圾评论。
- 回收：移入回收状态。

评论由主站岛屿实时读取，通过或回收评论通常不需要重建主站。

## 11. 运维页

入口：左侧导航“运维”。

运维页展示主站重建状态：

- 空闲
- 已排队
- 构建中
- 上次构建成功
- 上次构建失败

可以点击“手动重建”触发主站构建。下方会显示构建日志尾部。

适合手动重建的场景：

- 修改了 `content/` 文件但没有通过后台发布
- 主站页面看起来没有更新
- 部署后想确认静态产物重新生成

## 12. 常见问题

输入框点不了或焦点被编辑器抢走：

通常是前端版本未更新。先强刷后台：

```text
Ctrl + Shift + R
```

仍不行时让运维检查线上 JS/CSS 资源哈希是否为最新。

保存后主站没变化：

- 草稿不会触发主站重建。
- 已发布文章修改后需要点击“保存并重建”。
- 去“运维”页查看构建状态和日志。

登录失败：

- 确认使用的是后台口令，不是 VPS 密码。
- 如果返回“请先登录”，可能是会话过期，刷新后重新登录。
- 如果一直失败，需要在 VPS 上重设 `ADMIN_PASSWORD_HASH`。

发布失败并提示 slug：

- slug 只能是小写字母、数字和连字符。
- 示例：`hello-clay`
- 不要使用空格、中文、下划线或尾部连字符。

图片上传失败：

- 先保存一次草稿。
- 检查图片是否超过 20MB。
- 检查后端服务是否正常。
