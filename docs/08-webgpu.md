# 08 · WebGPU 炫技模块（clay-engine）

## 1. 目标与边界

`packages/clay-engine` 负责全站所有"真实粘土"模拟。目标：**让访客忍不住伸手碰一下，并且碰了之后会心一笑**。边界：

- 只出现在三处 —— 首页 hero、实验室 `/lab/*`、404（约定见 [04-motion.md](04-motion.md) §5）。
- 任何场景都是懒加载岛屿：进入视口才初始化，离开视口暂停渲染循环，页面隐藏（`visibilitychange`）即休眠。
- 任何能力档位下页面信息完整 —— 3D 永远是装饰，不承载内容。

## 2. 能力分级与降级链（`capability.ts`）

```
检测顺序（一次性，结果缓存于 sessionStorage）:
T0  navigator.gpu 可用 且 requestAdapter 成功     → WebGPURenderer（全特效）
T1  WebGL2 可用                                   → 同一套 Three/TSL 场景自动编译 GLSL
                                                    （关闭 compute 特效：指纹细分、粒子上限减半）
T2  WebGL 不可用 / prefers-reduced-motion /
    保存流量模式 / 低端设备(deviceMemory<4)        → 静态封面图（预渲染的粘土球 PNG + 微妙 CSS 呼吸）
```

选 Three.js TSL 的核心原因正在于此：**一套着色器代码，T0/T1 两档免费**（决策见 [01-tech-stack.md](01-tech-stack.md) §2）。运行时再叠一层**帧率自适应**：连续 2s 中位帧率 < 45fps → 自动降一档质量（DPR cap 1.5→1、关软阴影、减粒子），并在控制台友好打印（炫技的一部分是让同行看到你做了降级）。

为"手写过 WGSL"的炫技完整性，实验室保留一个**裸 WebGPU compute** 小玩具（§3.4），不走 Three。

## 3. 场景规格

### 3.1 首页 Hero：会记仇的粘土球

**视觉**：一颗哑光陶土球（`--clay-primary` 同色相），矿物颗粒细节，柔和环境光 + 一盏暖主光；材质用 TSL 实现**近似次表面散射**（边缘透光的暖红）+ matcap 兜底。

**交互**：

| 输入 | 反馈 |
| --- | --- |
| 指针悬停 | 球体朝指针方向轻微"吸附"鼓起（顶点位移，半径约球面 1/4） |
| 按住 | 按压点凹陷，深度随按住时长增加，伴随轻微整体压扁；**留下指纹凹痕**（位移贴图上叠加椭圆压痕 + 法线扰动） |
| 拖拽 | 球体被搓得旋转，带角动量阻尼 |
| 双击 | 戳一个洞然后慢慢"自愈"弹回（弹性恢复动画） |
| 闲置 10s | 凹痕缓慢自愈，球体做呼吸 idle 动画 |

**实现**：球体高分段 IcosahedronGeometry；形变在 TSL 顶点着色器中由一张 RG 位移纹理驱动；T0 用 compute pass 更新位移纹理（含弹性恢复模拟），T1 回退为 CPU 端低频更新（128² 纹理足够）。预算：JS+资产 ≤ 600KB（gzip，含按需的 three 模块），首帧出现 ≤ 1s（期间显示静态占位图做交叉淡入）。

### 3.2 实验室：捏泥工坊 `/lab/atelier`

自由雕刻玩具：

- 工具：推（凹）、拉（凸）、抹平、戳洞、旋转底盘（像拉坯机，长按底盘踏板球加速旋转）。
- 颜色：四款陶土色（与设计系统色板同源）。
- 导出：截图 PNG（带粘土风边框水印"捏于陶然"）；作品参数序列化成短码可分享（URL hash，无需后端）。
- 实现同 3.1 的位移纹理方案放大版（256² 位移图 + 更高分段），不做真体素雕刻（成本失控），文档明确这个取舍。

### 3.3 404：摔碎的陶罐

- 进入页面：一只陶罐从屏幕顶落下 → Rapier 物理 → 在"地面"摔碎成 12 块预切割碎片（凸包碰撞体）。
- 碎片可拖拽抛掷，互相碰撞；把任意 3 块拖近罐底轮廓 → 碎片磁吸归位 → 陶罐复原并鞠躬 → 彩蛋文案"修补完成，去首页看看？"。
- T2 降级：展示碎陶罐静态插画 + 文案，功能（搜索/回首页）不受影响。

### 3.4 实验室：泥点雨 `/lab/rain`（裸 WebGPU 玩具）

10 万颗粘土泥点粒子受指针引力场影响的 compute shader 玩具，手写 WGSL，页面附"查看着色器源码"折叠块 —— 纯炫技位，T0 专属，其他档位显示说明卡（"你的浏览器还烧不了这窑"）+ 录屏视频。

## 4. 资产与工程

- 模型：陶罐等用 Blender 制作，gltf + Draco 压缩；纹理 KTX2(basis)。单场景资产预算 ≤ 1.5MB。
- 共享上下文：同页多个 clay 场景共用一个 renderer/canvas（avoid 多 GPU device）。
- 内存：场景卸载时显式 dispose 几何/纹理/管线，路由切换（View Transitions）钩子中执行。
- 测试：capability 分级逻辑单测；三档各跑一条 Playwright 截图基线（T0 仅在本地 Chrome 跑）。
