# 00 · 项目总览

## 1. 愿景

做一个**像一团温暖陶土**的个人博客：读者来这里安静读文章，顺手能把页面上的物件"捏一捏"；同行来这里能看到现代 Web 技术（WebGPU、View Transitions、岛屿架构）被克制而漂亮地使用。

一句话定位：**内容为主的个人博客，以粘土拟物为统一视觉语言，以"可触摸感"为统一交互语言。**

## 2. 设计关键词

| 关键词 | 含义 | 落点 |
| --- | --- | --- |
| 粘土 Clay | 厚圆角、双内阴影、哑光质感、可挤压 | 设计系统全部组件 |
| 温暖 Warm | 陶土橘 × 奶油底 × 可可棕，纸张噪点 | 色板与材质 |
| 实用 Useful | 阅读体验第一：排版、目录、搜索、RSS | 主站功能规格 |
| 弹性 Squishy | 一切交互都有"捏下去弹回来"的回馈 | 动效系统 |
| 炫技 Showcase | WebGPU 实时粘土、物理、过场 | clay-engine 与实验室页 |

## 3. 核心原则（冲突时按序裁决）

1. **内容优先**：动效与 3D 永远不挡阅读。文章正文区内禁止常驻动画。
2. **性能底线**：首屏 LCP < 1.8s（4G 模拟），CLS = 0；炫技模块全部懒加载、可见才渲染。
3. **渐进增强**：基线是纯 HTML/CSS 可读可导航；JS、WebGL、WebGPU 是逐层加码，每层都有降级（见 [08-webgpu.md](08-webgpu.md)）。
4. **尊重用户**：`prefers-reduced-motion` 全站生效；暗色模式完整支持；无障碍对比度达 WCAG AA。
5. **数据自持**：文章是本地 MDX 文件，动态数据是单文件 SQLite，备份 = 拷走两个目录（见 [07-data.md](07-data.md)）。

## 4. 功能总览

### 主站（读者侧）

- 首页：WebGPU 可互动粘土主视觉 + 精选/最新文章
- 文章：列表、详情（目录/进度/代码高亮/灯箱）、归档、标签
- 动态（Moments）：短内容流，类似"说说"
- 友链、关于、404（粘土摔碎彩蛋）
- 实验室（Playground）：捏泥工坊等炫技小玩具
- 评论（无需注册，轻量审核）、点赞（"捏一下"）、浏览量
- 站内搜索（Pagefind 静态索引）、RSS、Sitemap、自动 OG 图

### Admin 站（作者侧，单用户）

- 仪表盘：访问统计、最近评论、内容概况
- 写作：TipTap 富文本 ⇄ Markdown 源码双模编辑、图片粘贴即传、草稿与定时发布
- 管理：动态、评论审核、友链、资源库、站点设置
- 运维：一键备份导出、触发主站重建

详见 [05-site-web.md](05-site-web.md) 与 [06-site-admin.md](06-site-admin.md)。

## 5. 非目标（明确不做）

- ❌ 多作者 / 多租户 / SaaS 化 —— 单用户，永远。
- ❌ 用户注册体系 —— 评论用昵称+邮箱即可。
- ❌ 重 CMS（工作流、版本审批）—— git 就是版本系统。
- ❌ 动效堆砌 —— 任何动效先回答"它让内容更好读了吗 / 它有趣到值得 80ms 吗"。

## 6. 目标环境

- 现代常青浏览器（Chrome/Edge/Safari/Firefox 最近两个大版本）
- WebGPU 仅作增强：Chromium 桌面端全量、Safari 26+；其余走 WebGL/静态降级
- 移动端完整可用（炫技模块在低端机自动降级）
