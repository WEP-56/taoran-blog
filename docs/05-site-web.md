# 05 · 主站功能规格

## 1. 站点地图

```
/                       首页
/posts/                 文章列表（分页）
/posts/[slug]/          文章详情
/archive/               归档（按年时间轴）
/tags/                  标签总览
/tags/[tag]/            某标签下文章
/moments/               动态流
/friends/               友链
/about/                 关于
/lab/                   实验室索引
/lab/[toy]/             各炫技玩具
/404                    彩蛋 404
/rss.xml  /sitemap.xml  /og/[slug].png
```

全局壳：顶部导航（logo 泥团 + 链接 + 搜索 + 主题切换），页脚（订阅/备案/版权/"本站是块粘土"小字彩蛋）。移动端导航折叠为底部粘土 dock。

## 2. 逐页规格

### 2.1 首页 `/`

| 区块 | 内容 |
| --- | --- |
| Hero | 左：站名（霞鹜文楷大字）+ 一句话简介 + 两个 ClayButton（开始阅读 / 关于我）；右：clay-engine 可互动粘土球（[08-webgpu.md](08-webgpu.md)）。球下方一行小字提示"按住试试"。 |
| 精选 | 置顶文章 1 篇大卡 + 最新 4 篇小卡，滚动入场动效见 [04-motion.md](04-motion.md) §4.1 |
| 标签云 | 高频标签 ClayTag 流式排布 |
| 最近动态 | 最新 3 条 moments 摘要 |

### 2.2 文章列表 `/posts/`

- ClayCard 双栏（移动端单栏）：封面（LQIP 占位）、标题、摘要、日期、标签、阅读时长。
- 分页（每页 12 篇）用静态分页路由，不做无限滚动（利于回退、SEO、静态化）。

### 2.3 文章详情 `/posts/[slug]/`

核心页面，排版规格从严：

- **头部**：封面、标题、日期/更新时间、标签、阅读时长、浏览量（岛屿异步填充）。
- **正文**（MDX 管线产出，见 [07-data.md](07-data.md) §3）：
  - 标题锚点 hover 出现"泥点"链接图标；
  - 代码块：Shiki 陶土主题、行号、文件名标签、一键复制（按钮压扁反馈）；
  - 图片：派生多尺寸 + 灯箱（点击像把泥片拿到面前）；
  - 引用块、提示框（note/warn/tip 三色 ClayCard 变体）；
  - 脚注侧边气泡（桌面端 hover 即现）。
- **右侧目录**（lg 以上）：滚动 spy 高亮，当前项有小泥球指示；移动端收进底部抽屉按钮。
- **顶部阅读进度**："搓泥条"（[04-motion.md](04-motion.md) §4.4）。
- **文末**：上一篇/下一篇、"捏一下"点赞按钮（带计数）、评论区。
- **评论区**（岛屿，懒加载）：昵称 + 邮箱（Gravatar/泥猫默认头像）+ 内容，支持单层回复；提交后显示"待晾干（审核中）"状态。规则见 [06-site-admin.md](06-site-admin.md) §3.4。

### 2.4 归档 `/archive/`

按年分组的时间轴，轴线是一根手绘泥条，每年节点是一颗泥球；条目仅标题+日期，密度高。

### 2.5 动态 `/moments/`

类朋友圈单列流：文字 + 最多 9 图 + 可选位置/心情 emoji。卡片像一张张便签泥片，随机 ±1° 旋转。

### 2.6 友链 `/friends/`

每个朋友是一张"陶土名片"：头像、名字、一句话、链接；hover 翻起一角。页尾申请友链说明 + 本站信息卡（一键复制 JSON）。

### 2.7 关于 `/about/`

内容来自 `content/pages/about.mdx`。含可拖拽贴纸彩蛋（[04-motion.md](04-motion.md) §5）、装备/书影音清单、时间线。

### 2.8 实验室 `/lab/`

炫技玩具索引页，每个玩具一张卡说明所需能力（WebGPU/WebGL 徽章）。首发玩具见 [08-webgpu.md](08-webgpu.md) §3。

### 2.9 404

陶罐摔碎交互彩蛋（[08-webgpu.md](08-webgpu.md) §3.3）+ 搜索框 + 回首页按钮。

## 3. 全局功能

| 功能 | 规格 |
| --- | --- |
| 搜索 | Pagefind 静态索引；`Ctrl/⌘+K` 唤起 ClayDialog，结果高亮命中词；构建期生成索引 |
| 主题 | 亮「日晒陶坊」/ 暗「窑变之夜」/ 跟随系统；切换动效见 [04-motion.md](04-motion.md) §4.3；首屏内联脚本防闪烁 |
| RSS | 全文输出 `rss.xml`；另提供 JSON Feed |
| SEO | 每页 title/description/canonical；文章页 JSON-LD（BlogPosting）；`og/[slug].png` 构建期用 satori 按粘土风模板生成 |
| 浏览量 | 页面可见 5s 后岛屿上报 `POST /api/views`（去重策略见 [07-data.md](07-data.md)） |
| 字体 | 子集化分片加载（[03-design-system.md](03-design-system.md) §4） |
| 离线 | 不做 PWA（非目标）；仅缓存字体与静态资源的长 max-age |

## 4. 性能与质量指标（CI 卡线）

| 指标 | 目标 |
| --- | --- |
| LCP（4G 模拟，文章页） | < 1.8s |
| CLS | 0 |
| INP | < 200ms |
| 首屏 JS（文章页，不含懒加载岛屿） | < 60KB gzip |
| Lighthouse（Perf/A11y/SEO） | ≥ 95 / 100 / 100 |
| 文章页无 JS 可读 | 是（评论/点赞等岛屿显示降级提示） |
